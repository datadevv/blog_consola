# Blog por consola

Este proyecto es un sistema de blog desarrollado en Python que permite ver publicaciones, buscar por título, filtrar por etiquetas y validar la estructura de los posts.

La idea del proyecto es mantener el blog en una estructura modular para que el código quede más ordenado y fácil de mantener.
